## Content pillars
1. **Problem to solution** (migration, ERP, data pipelines): before/after, numbers.
2. **Case studies**: client problem, approach, result (with permission).
3. **Engineering notes**: tips, architecture diagrams, mistakes avoided.
4. **Lifecycle proof**: build, deploy, train; show adoption.
5. **Team and culture**.

## LinkedIn post anatomy
Hook line (under 120 chars) / blank line / 3-5 short lines / CTA / 3-5 hashtags.

## Reel structure (15-30 s)
0-2 s hook text / 2-20 s one idea (screen recording or diagram, captions on) / last 3 s end card (logo + codeslytic.com).

## Rendering templates to image/PDF
Open the HTML in Chrome:
- Social/reel/carousel: DevTools, select the `.post` / `.r` / `.s` element, "Capture node screenshot".
- Invoice/proposal/brochure: Print, Save as PDF, margins None, Background graphics ON.
